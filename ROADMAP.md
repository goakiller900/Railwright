# Railwright Roadmap

Railwright 0.3.8 adds optional runtime-managed dynamic names without attempting a broad rewrite of the existing station circuit system. The next milestones focus on modernising those inherited foundations and improving integrations and reusable configuration workflows.

## Current priority — Factorio 2.1 circuit foundations

- Perform the broader update of circuit blueprints inherited from before Factorio 2.0.
- Review advanced dynamic train-limit arithmetic as part of that circuit work.
- Keep dynamic station naming compatible with future circuit changes without changing its exactly-one-resource rule by default.

## Network integrations

- Investigate optional Cybersyn 2 support.
- Evaluate possible Cybersyn and LTN support through optional integrations.
- Keep Space Age and third-party logistics mods optional rather than hard dependencies.

## Configuration workflow

- Add saveable, named Railwright presets.
- Add configuration import and export.
- Improve capability detection for unusual compatible modded entities.

## Accessibility

- Add additional localisation languages.

The roadmap is intentionally flexible. Correct blueprint generation, deterministic runtime behavior, and safe save compatibility take priority over adding more options quickly.
